This project serves to make it easy to modify and manipulate the data of 2015's 'World Happiness Report'. It takes a CSV, and provides a command line interface for exploring the data, and the variables' relationships with one another. 

Features:
- Reverting to the original CSV from a working copy
- Sorting by column (ascending or descending)
- Filter (by one or more variables)
- Aggregate (mean/median/sum of a chosen column)
- Correlate (calculate correlation between two columns w/ clear English explanation)
- Display (prints current dataframe out)

Setup:
1. git clone ...
2. cd project
3. python -m venv venv
4. source venv/Scripts/activate
5. pip install -r requirements.txt
6. python main.py
7. Run!
